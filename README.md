# Hi, I'm Shivam Kumar Yadav

**I build AI automation tools for small businesses: chatbots trained on your docs, document data extraction, price monitoring, and n8n workflows.**

I turn repetitive office work into small, reliable tools. I work fixed-price, hand over the full source code, and deploy everything in your own accounts, so you are never locked in to me.

## Projects (all open source, MIT)

| Project | What it does | Live demo | Stack |
|---|---|---|---|
| [**DocsChat**](https://github.com/shivam911898/docschat) | AI chatbot trained on your documents. Answers only from your PDFs and FAQs, shows its sources, captures leads, and embeds on your site with one line. | [Try it](https://docschat-one.vercel.app) | Next.js 15, TypeScript, BM25 / Gemini-embeddings RAG, SQLite / Turso |
| [**DocExtract**](https://github.com/shivam911898/docextract) | Turns invoices and receipts into validated Excel / CSV / Google Sheets rows, with a "Needs review" queue for anything that does not add up. | [Try it](https://docextract-9vrp.onrender.com) | Python, Streamlit, Groq / Gemini, optional Docling OCR |
| [**PriceWatch**](https://github.com/shivam911898/pricewatch) | Competitor price and stock monitor. Polite scraping, undercut and out-of-stock alerts (Telegram / Sheets), live charts dashboard, AI weekly summary. | [Try it](https://pricewatch-x0x8.onrender.com) | FastAPI, SQLite, Docker, optional Browser-use agent |
| [**n8n Automation Pack**](https://github.com/shivam911898/n8n-automation-pack) | 5 importable workflows (AI lead scoring, inbox triage, daily KPI report, Shopify order alerts, document intake) plus a Coolify-ready self-host stack. Validated by importing into a real n8n. | Workflows, no UI | n8n, Docker, Groq API |

DocExtract and PriceWatch run on free Render instances: they sleep after 15 minutes idle, so the first load can take about a minute. DocsChat runs on Vercel and loads instantly.
